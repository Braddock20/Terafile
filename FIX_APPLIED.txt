Render startup failure fixed.

Cause:
Playwright npm package was 1.62.1 while the Docker image was v1.55.0-noble.
The browser binary version must match the Playwright package version.

Fix:
- package.json: playwright 1.62.1
- Dockerfile: mcr.microsoft.com/playwright:v1.62.1-noble

This matches the exact version requested by the Render error.
